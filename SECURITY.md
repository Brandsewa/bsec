# Security policy

bsec is a multi-tenant commerce platform. If you find a vulnerability, please report it privately.

- **Report:** use GitHub's private vulnerability reporting: the **Security** tab of this repository, then **Report a vulnerability**. Please do not open a public issue or pull request for a security problem.
- **Include:** what you found, the steps to reproduce it, and the impact (especially anything that crosses between stores/tenants or exposes customer data).
- **What to expect:** we will acknowledge a report as soon as we can, keep you updated, and credit you if you wish once a fix is released.
- **Please do not:** access data that is not yours, run denial-of-service or load tests, or test against production stores you do not own.

Only the latest `main` is supported.
